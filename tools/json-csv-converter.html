Convert a JSON array of objects to CSV format, or convert CSV back to JSON. Great for spreadsheet export.

About JSON to CSV Converter

What input format does this tool expect?

For JSON to CSV, paste a JSON array of objects (e.g. [{"name":"John"},{"name":"Jane"}]). For CSV to JSON, paste comma-separated values with a header row.

Does it handle nested objects?

Nested objects are flattened using dot notation (e.g. "address.city" becomes a column header).

Can I download the result?

Yes. Click Download to save the output as a file.
