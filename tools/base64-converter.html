About Base64 Converter

What is Base64 encoding?

Base64 is an encoding scheme that converts binary data into ASCII text. It is commonly used to embed data in URLs, emails, and JSON.

Is Base64 encryption?

No. Base64 is encoding, not encryption. It does not provide security. Anyone can decode it.

Does this support Unicode/UTF-8?

Yes. This tool properly handles UTF-8 characters, including emoji and non-Latin scripts.

Why does my encoded string end with an equals sign?

That is padding, not an error. Base64 encodes bytes in groups of three, so when your text does not divide evenly the final group is padded with = (or == if two bytes were left over). Decoders ignore it.

Can I encode an image or other file here?

Not directly. This page works with text: paste the text you want to encode, or a Base64 string you want to decode. Turning a file into Base64 means reading it as bytes first, which a text box cannot do.
