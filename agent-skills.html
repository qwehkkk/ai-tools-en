How to install an agent skill (60 seconds)

  1. Claude Code: copy the skill folder into .claude/skills/ in your project, or install plugins via /plugin from the official catalog.
  2. Codex / Gemini CLI / others: most skills are plain instructions plus scripts — drop them where your agent reads project context (AGENTS.md, config folder), or follow the repo's README.
  3. Cursor: use the plugin registry (cursor/plugins above) or point Rules at the skill's instructions.
  4. Start with one or two skills, not ten. Skills interact; keep only the ones that measurably improve output.
