About GetToolkit

A handful of small utilities, built to be boring in the best way: they open fast, they work offline, and they never phone home.

GetToolkit is a collection of everyday developer and text tools — format JSON, decode a string, compress an image, generate a UUID, hash some text. Nothing here is novel. You can find a version of each of these in a dozen other places, many of them stuffed with pop-ups, forced sign-ups, or an upload step that quietly sends your data to a server you have never heard of.

This site exists because that last part is a genuine problem. People paste API responses, database dumps, and configuration files into whichever tool ranks first. Often those tools work fine. Sometimes the thing you pasted is a private key.

How it works

Every tool here is a single HTML page with a bit of plain JavaScript. When you load a tool, your browser downloads the page and the script that powers it. That is the entire interaction. There is no application server, no database, and no endpoint that receives your input — the code that formats your JSON or hashes your text is already running on your own machine by the time you type the first character.

The practical consequences:

  • Your input stays local. Text you type, files you drop in, images you compress — none of it is uploaded. You can verify this yourself: open your browser’s Network tab, then use any tool on the site.
  • It works offline. Once a tool page has loaded, disconnecting from the internet does not break it.
  • There is nothing to sign up for. No account, no email address, no usage limit, no export button hidden behind a paywall.

The only exception worth naming is how the pages get to you. They are served as static files by a content delivery network, and the usual web server logs apply to that request — IP address, browser, timestamp. Details are in the privacy policy.

What is on the site

Twelve tools at the moment, covering the things that come up most often: JSON formatting and validation, JSON to CSV conversion, Base64 encoding, URL encoding, HTML entity escaping, MD5 and SHA hashing, UUID generation, Unix timestamp conversion, color conversion, word and character counting, Lorem Ipsum placeholder text, and in-browser image compression.

The list grows slowly and on purpose. A tool gets added when it is something we actually needed and could not find a clean version of, or when enough people ask for it. Half-finished tools and features nobody requested are not worth the maintenance.

Why there are ads

Hosting is cheap but not free, and there is no paid tier to subsidise it. If advertising appears on the site, it is there to cover that cost and nothing more — no interstitials, no pop-unders, no “continue reading” gates between you and the tool you clicked on. The privacy policy explains what ad providers can and cannot do with cookies.

Found a bug?

Some of these tools handle edge cases that are genuinely unpleasant — malformed JSON with a BOM, a timestamp far outside the range JavaScript dates handle well, a 30 MB photo on a phone with limited memory. If something produces a wrong answer or throws an error, that is worth fixing. The contact page explains how to report it, including what details make a report actionable.

Who runs this

GetToolkit is an independent project, maintained by a software developer who spent years building line-of-business systems and got tired of watching colleagues paste credentials into random websites to decode them. It is not a company, it has no investors, and it does not collect profiles of its visitors. Just a set of tools, kept working.
